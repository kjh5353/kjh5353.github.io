클라우드 동기화 설정
연결 안 됨
  1. Firebase 프로젝트 만들기
    console.firebase.google.com → 프로젝트 추가 → 이름 입력 → 생성
  2. Firestore 데이터베이스 생성
    왼쪽 메뉴 Firestore Database → 데이터베이스 만들기 → 테스트 모드 선택 → 위치 선택 후 완료
  3. 웹 앱 등록 및 설정 복사
    프로젝트 개요 → ⚙️ → 프로젝트 설정 → 하단 내 앱 → </> 웹 아이콘 클릭 → 앱 이름 입력 후 등록 → firebaseConfig 객체 복사
  4. 보안 규칙 설정
    Firestore → 규칙 탭 → 아래로 교체 후 게시:
    allow read, write: if true;
  5. 설정 탭에 붙여넣기 → 연결하기
    동기화 ID를 복사해서 아이폰에서도 동일하게 입력하면 실시간 동기화 시작!
